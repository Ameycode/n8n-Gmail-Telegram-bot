# n8n Gmail to Telegram Notification Workflow

## Overview

This workflow automatically sends Telegram notifications whenever a new Gmail message is received.

## Workflow

Gmail Trigger → Telegram Send Message

## Features

* Monitors Gmail inbox
* Sends email previews to Telegram
* Real-time notifications
* Built with n8n

## Setup

1. Import the workflow JSON into n8n
2. Configure Gmail credentials
3. Configure Telegram Bot credentials
4. Publish the workflow
